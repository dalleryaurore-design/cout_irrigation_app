L'investissement initial (CAPEX) est converti en une annuité constante, c'est-à-dire le montant qu'il faudrait verser chaque année pendant la durée de vie de l'équipement pour rembourser le capital et sa rémunération au taux d'actualisation.

Annuité = CAPEX × (1 − taux de subvention) × a   avec   a = i (1 + i)n / [(1 + i)n − 1]

  • taux de subvention : {% if contexte == 'acces' %}de l'ouvrage et du réseau d'amenée, propre à chaque type d'accès (45 % pour le forage, taux général sinon){% else %}du matériel d'irrigation{% endif %} ;
  • i : taux d'actualisation ({% if contexte == 'acces' %}accès à la ressource{% else %}équipements{% endif %}) ;
  • n : durée de vie en années ;
  • a : facteur d'annualisation, appelé ici « taux d'amortissement annuel ». Si i = 0, a = 1/n (amortissement linéaire).
